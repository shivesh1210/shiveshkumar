This project aims to develop a robot-as-a-service (RaaS) dual-purpose double pendulum robot which can be used as an Acrobot and Pendubot platform for dynamics, control theory and machine learning education and research. The system should have low energy consumption, connected to a cloud service and hence remotely accessible so that students, researchers and industry professionals can test their algorithms remotely.
